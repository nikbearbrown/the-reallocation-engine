# course/ — course-admin space, by term

    course/assignments/            assignment specs
    course/<term>/submissions/<github-handle>/   your justification, worked run, reports

You may only create files under your own handle's directory. Code goes in
`scripts/contrib/<term>/<handle>-*/`; recipes in `recipes/cases/<term>/`;
run entries in `logs/runs/`. See CONTRIBUTING.md for the full contract.
