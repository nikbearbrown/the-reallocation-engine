# recipes/cases/ — student case recipes, by term

A student recipe is born here (`cases/<term>/<handle>-<slug>.md` + `.card.md`)
and can only enter top-level `recipes/` by maintainer promotion, which
requires lifecycle status ≥ RUNNABLE-SAMPLE with its RUN_LOG evidence link
filled in. The directory encodes "assignment artifact"; promotion encodes
"operating surface." Honest frontmatter is graded: `status: VERIFIED` with
`attestation: null` is a contract violation, not a promotion.
